## Problem Statement

Given a positive integer N, determine whether it is a palindrome.

Note: A number is called a palindrome if it reads same backwards and forwards.

### Input
The first and only line of input contains a positive integer N.

### Output
Print "Yes" if the given number is a palindrome, otherwise "No" (without quotes).

### Example
Input
54145
Output
Yes
Explanation
The given number reads same backwards and forwards. Thus it is a palindromic number.

Input
12345
Output
No
