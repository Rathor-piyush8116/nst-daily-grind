## Problem Statement

You are given two integers representing the length and breadth of a rectangle.

You need to print "Square" if the given rectangle is square as well, otherwise print "Rectangle".

### Input
The first and only line of input contains two space-separated integers, representing the length and breadth of the rectangle respectively.

### Output
Print "Square" or "Rectangle" based on the dimensions.

### Example
Input
5 5
Output
Square

Input
10 9
Output
Rectangle
