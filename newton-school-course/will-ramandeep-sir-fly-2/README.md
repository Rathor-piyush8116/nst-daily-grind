## Problem Statement

Ramandeep Sir is known for his highly selective flying decisions after past flight troubles. He follows a strict set of rules before agreeing to board a plane.

Here are his conditions:

 
 If the trip is international, Ramandeep Sir will not fly, regardless of any other conditions.

 

 
 If the trip is domestic, and the flight duration is less than or equal to 1.5 hours, he will fly.

 

 
 If the trip is domestic and the duration is more than 1.5 hours, he will not fly if:

 
 
 His seat is a middle seat, or

 

 
 The airline is IngidoX

 

 
 

In all other cases, he will fly.

Your task is to determine whether Ramandeep Sir will fly given the flight details.

### Input
The input consists of four lines:

 * The first line contains a floating-point number d — the duration of the flight in hours.
 * The second line contains a string seat_type — one of "window", "middle", or "aisle".
 * The third line contains a string airline — the airline name (case-sensitive, no spaces).
 * The fourth line contains a string trip_type — either "domestic" or "international".
 

### Output
Print a single line as following:
 * Ramandeep Sir will fly — if he agrees to board the flight.
 * Ramandeep Sir will not fly — otherwise.
 

Note: Output must exactly match the above (case-sensitive, no extra spaces).
