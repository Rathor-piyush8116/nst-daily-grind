## Problem Statement

Given a single positive integer N, write a recursive program to print the sequence of numbers starting from N up to 1, followed immediately by numbers from 1 back down to N.

You must solve this problem using recursion without using any iterative loops (for, while, or do-while).

### Input

* A single line containing a single integer N.

### Output

* Print a single line containing space-separated integers representing the sequence from N to 1 and then 1 back down to N.

### Example
Input 1
4
Output 1
4 3 2 1 1 2 3 4

Explanation:
Numbers descending from 4 to 1: 4 3 2 1
Numbers ascending from 1 back to 4: 1 2 3 4 
Combined output: 4 3 2 1 1 2 3 4

## Solution

```py
// ─── 13 ───
n = int(input())
def recursive_pr(n):
    if n<1:
        return
    print(n,end=" ")
    recursive_pr(n-1)
    print(n,end=" ")
recursive_pr(n)

```
