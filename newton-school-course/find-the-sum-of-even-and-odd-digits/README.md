## Problem Statement

You are given a positive integer N. Your task is to separately find the sum of its even digits and the sum of its odd digits.

### Input
The first and only line of input contains a positive integer N.

### Output
Print two space-separated integers, representing the sum of even and odd digits in the given number N.

### Example
Input
295892
Output
12 23
Explanation
The even digits in the given number are: 2, 8, and 2.
And the odd digits in the given number are: 9, 5, and 9.
Thus the sum of even and odd digits will be 12 and 23 respectively.

## Solution

```js
// ─── 2 ───

n=int(input())
sumE=0
sumO=0
while n!=0:
    nl=n%10
    if nl%2==0:
        sumE+=nl
    else:
        sumO+=nl
    n=n//10
print(sumE,sumO)

// ─── 3 ───
295892
```
