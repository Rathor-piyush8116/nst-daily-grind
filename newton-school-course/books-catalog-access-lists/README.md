## Problem Statement

You are given a list of book titles. Your task is to complete a function access_books(book_list) that performs the following operations:

 * Print the first book in the list.

 * Print the last book in the list.

 * Print a list of the first three books using slicing.

 * Print a list of the last three books using negative indexing.

 * Print a list of every second book in the list (i.e., alternate books starting from the first).

### Input
User Task
Since this is a functional code, you don't have to take any input you just need to complete the function access_books() which takes list of books book_list as parameter.
Custom Input
The input consists of multiple lines.
Each line contains a single string representing the title of a book.
The last line of the input will always be the word "stop", which indicates the end of the input and should not be included in the list of book titles.

### Output
Print the appropriate list of books as mentioned in question in separate lines.
