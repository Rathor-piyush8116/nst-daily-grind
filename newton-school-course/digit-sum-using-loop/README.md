### Output

Explanation
The digits of the given number are: 2, 8, 3, 9 and 3. And their sum is 25.

// ─── 12 ───
def sum_of_digits(N):
    total = 0
    while N > 0:
        rem = N%10
        total = total+rem
        N= N//10
    return total
