## Problem Statement

You are given three integers a, b, and c.

A built-in function greater(x, y) is available to you. It returns the greater of the two values x and y.

Your task is to find the greatest among the three given numbers using the greater() function.

Note: You must use the provided greater() function. Do not compare all three numbers directly.

### Input
The first line contains three space-separated integers a, b, and c.

### Output
Print a single integer &mdash; the greatest among the three numbers.

### Example
Example 1
Input

Output

Example 2
Input
