## Problem Statement

You are given two functions:

 
 greater(a, b) &rarr; prints the greater of two integers a and b.

 

 
 smaller(a, b) &rarr; prints the smaller of two integers a and b.

 

Note: You should call these functions as required

Write a program that takes:

 
 A single character input: "G" for greater or "S" for smaller

 

 
 Two space-separated integers

 

Task:
If the character is "G", print the greater of the two numbers .
If the character is "S", print the smaller of the two numbers .

 

### Input
* The first line contains choice: A single character, either "G" or "S"

* The second line contains a, b: Two space-separated integers

* a!=b

### Output
Print the greater or smaller of the two numbers as per input constraints.

### Example
Input
G
4 9

Output
9

Explanation
"G" means print the greater number.
Between 4 and 9, the greater is 9, so the output is 9

## Solution

```py
// ─── 9 ───
def greater(a, b):
    if a > b:
        print(a)
    else:
        print(b)


def smaller(a, b):
    if a < b:
        print(a)
    else:
        print(b)


choice = input()
a, b = map(int, input().split())

if choice == "G":
    greater(a, b)
elif choice == "S":
    smaller(a, b)
```
