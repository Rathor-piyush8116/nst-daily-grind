## Problem Statement

You are given a number. Your task is to check if this number is an Armstrong number.

An Armstrong number is a number that is equal to the sum of its own digits, each raised to the power of the number of digits.

### Input
First line will contain an Integer N.

### Output
Print True if the number is Armstrong, otherwise print False.

### Example
Input:
153
Output:
True
Explanation
The number 153 has 3 digits: 1, 5, and 3.
If we raise each digit to the power of 3 (the total number of digits) and sum them:
13 + 53 + 33 = 153
Since the sum is equal to the original number, 153 is an Armstrong number.

Input:
12
Output:
False
Explanation
The number 12 has 2 digits: 1 and 2.
If we raise each digit to the power of 2 (the total number of digits) and sum them:
12 + 22 = 5
Since the sum is not equal to the original number, 12 is not an Armstrong Number.

## Solution

# Your code here
num = int(input())
num_copy = num
digit_count = 0
arsum = 0

while num_copy > 0:
    digit_count += 1
    num_copy //= 10

num_copy = num

while num_copy > 0:
    digit = num_copy % 10
    arsum += digit ** digit_count
    num_copy //= 10

if arsum == num:
    print(True)
else:
    print(False)
