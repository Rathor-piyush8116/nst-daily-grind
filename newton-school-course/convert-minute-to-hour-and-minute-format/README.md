## Problem Statement

Write a program to convert total minutes into hours and remaining minutes.

Print the hours and minutes in the below given format:

Time: {x} hour(s) and {y} minute(s)

where {x} will be replaced by hours and {y} by minutes.

### Input
The first and only line of input contains a single integer, representing the total minutes.

### Output
Print the hours and minutes in the below given format:
Time: {x} hour(s) and {y} minute(s)
where {x} will be replaced by hours and {y} by minutes.

### Example
Input
135
Output
Time: 2 hour(s) and 15 minute(s)

Input
60
Output
Time: 1 hour(s) and 0 minute(s)

## Solution

```js
total = int(input())

hours = total // 60
minutes = total % 60

print("Time:", hours, "hour(s) and", minutes, "minute(s)")
```
