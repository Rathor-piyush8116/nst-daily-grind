## Problem Statement

You are provided with a function sum_of_digits(n), where the integer n is passed as a parameter.

### Input
You don't need to take the input.

### Output
You need to return the sum of digits of n.

### Example
Input
28393
Output
25
Explanation
The digits of the given number are: 2, 8, 3, 9 and 3. And their sum is 25.

## Solution

```py
// ─── 7 ───
def sum_of_digits(n):
    if n == 0:
        return 0
    return (n % 10) + sum_of_digits(n // 10)
```
