## Problem Statement

You are given the codeforces ratings of four users - Arjun, Balram, Champaklata and Damodar.

Determine which user has the highest rating.

Note: All four users have distinct ratings.

### Input
First and only line contains 4 space separated Integers representing the ratings of Arjun, Balram, Champaklata, and Damodar respectively.

### Output
Print a single string denoting the name of person with highest rating.

### Example
Input:
1244 1006 1433 1222

Output:
Champaklata

## Solution

```py
# Your code here
a, b, c, d = map(int, input().split())

if a > b and a > c and a > d:
    print("Arjun")
elif b > a and b > c and b > d:
    print("Balram")
elif c > a and c > b and c > d:
    print("Champaklata")
else:
    print("Damodar")
```
