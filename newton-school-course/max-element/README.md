## Problem Statement

You are given a list of integers. Your task is to write a program to find and print the maximum element in the list.

### Input
The first and only line of input contains space-separated integers representing the elements of the list.

### Output
Print a single integer: the maximum element from the list.

### Example
Input
3 17 9 2 25 6
Output
25
Explanation
In the list [3, 17, 9, 2, 25, 6], the largest number is 25.

Input
7 4 9 1 6
Output
9
Explanation
In the list [7, 4, 9, 1, 6], the largest number is 9.

## Solution

```js
// ─── 12 ───
nums = list(map(int, input().split()))

curr_max = nums[0]
for val in nums:
  if val > curr_max:
    curr_max = val

print(curr_max)

// ─── 17 ───
25
```
