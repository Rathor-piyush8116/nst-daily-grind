## Problem Statement

You are given a list of positive integers. Your task is to sort the list in ascending order.

### Input
The first and only line of input contains space-separated integers, representing the elements of the list.

### Output
A single line of space-separated integers, representing the sorted list.

### Example
Input
3 17 9 2 25 6
Output
2 3 6 9 17 25
Explanation
The given list is printed in the sorted order - 2 3 6 9 17 25.

Input
7 4 9 1 
Output
1 4 7 9
Explanation
The given list is printed in the sorted order - 1 4 7 9.

## Solution

```js
// ─── 27 ───
num = list(map(int, input().split()))
n = len(num)

for i in range(n):
  for j in range(0, n - i - 1):
    if num[j] > num[j + 1]:
      num[j], num[j + 1] = num[j + 1], num[j]

print(*num)

```
