## Problem Statement

You are given a positive integer N.

Your task is to print a Z-shaped pattern of asterisks (*) such that:

 * The pattern has exactly N rows and N columns.

 * Each asterisk must be followed by a single space.

Note - Refer to the example output to clearly understand the required pattern.

### Input
The first and only line of input contains a single integer - N.

### Output
 Print a Z pattern using asterisks (*).

### Example
Input
5
Output

* * * * *
 *
 *
 *
* * * * * 

Input
4
Output

* * * * 
 *
 *
* * * *

## Solution

```js
// ─── 2 ───
n = int(input())
for i in range(1,n+1):
    for j in range(1,n+1):
        if i == 1 or i == n or i+j == n+1:
            print("*",end=" ")
        else:
            print(" ",end=" ")

    print()
```
