## Problem Statement

You look after the website of your college&#39;s Robotics Club. A new version of the website is ready, and it changes some file and folder names. Before you make these changes, you must save a backup of the current website. If something goes wrong, the backup can be used to bring the old website back.

Given Directory Structure

website/
├── index.html
├── about.html
├── css/
│ └── style.css
└── assets/
 └── logo.png

Tasks

Do these steps in order, starting from the current folder:

 * Create a folder named backup in the current working directory. 

 * Copy website/index.html into backup.

 * Copy website/about.html into backup. Name the copy about_old.html.

 * Copy the whole website/css folder, with everything inside it, into backup.

 * Rename the folder website/assets to website/images.

 * Rename the file website/index.html to website/home.html.

Expected Structure

backup/
├── index.html
├── about_old.html
└── css/
 └── style.css
website/
├── home.html
├── about.html
├── css/
│ └── style.css
└── images/
 └── logo.png

Note: Steps 2, 3 and 4 make copies. The original files must stay inside website.
