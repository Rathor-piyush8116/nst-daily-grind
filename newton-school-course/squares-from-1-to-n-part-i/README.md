## Problem Statement

You are given a positive integer N. Your task is to print the squares of all integers from 1 to N, one per line.

In other words, print:
1&sup2;, 2&sup2;, 3&sup2;, ..., N&sup2;, each on a separate line.

### Input
The first and only line of input contains a single integer N.

### Output
Print N lines, where the i-th line contains the square of integer i, where 1 \le i \le N

### Example
Input
5
Output
1 
4 
9 
16 
25

Input
3
Output
1 
4 
9

## Solution

```js
// ─── 9 ───
n=int(input())
for i in range(1,n+1):
    print(i**2)

// ─── 12 ───
1
4
9
16
25
```
