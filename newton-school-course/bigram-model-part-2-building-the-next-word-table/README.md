## Problem Statement

To suggest the next word, a phone keyboard must remember which words came after each word in the text it learned from. A bigram model keeps this in a next-word table. For every word in the text, the table lists the words that came right after it.

This is part 2 of building a bigram model. In part 1, you listed the bigrams of a sentence: the pairs of words that appear one right after the other. In this part, you collect them into a next-word table.

For example, the text i love cats i love dogs i hate rain has these bigrams:

i love
love cats
cats i
i love
love dogs
dogs i
i hate
hate rain

Its next-word table is:

i: love love hate
love: cats dogs
cats: i
dogs: i
hate: rain
rain: NONE

The word i appears three times. It is followed by love, then by love again, and then by hate. The word rain appears only at the end of the text, so no word comes after it.

Task

Write a program that reads a text and prints its next-word table.

 * Print one line for each different word in the text. Print a word only once, even if it appears many times.

 * Print the lines in the order in which the words first appear in the text.

 * On each line, print the word, a colon, one space, and then the words that came right after it, separated by single spaces.

 * List the next words in the order in which they appear in the text. If the same word came after it more than once, list it every time.

 * If no word ever came right after a word, print NONE after the colon and the space. This happens when the word appears only at the end of the text.

### Input
A single line containing the text. The text has N words. The words are in lowercase and are separated by single spaces.

### Output
One line for each different word in the text, in the order in which the words first appear, in the form word: next1 next2 ...

If no word came right after a word, its line is word: NONE

## Solution

```py
// ─── 2 ───


# For every different word, in the order it first appears, print:
#   word: next1 next2 ...
# Print NONE after the colon if no word came right after it.

words = input().split()

next_table = {}

for i in range(len(words)):
    word = words[i]

    if word not in next_table:
        next_table[word] = []

    if i < len(words) - 1:
        next_table[word].append(words[i + 1])

for word in next_table:
    if len(next_table[word]) == 0:
        print(word + ": NONE")
    else:
        print(word + ": " + " ".join(next_table[word]))
```
