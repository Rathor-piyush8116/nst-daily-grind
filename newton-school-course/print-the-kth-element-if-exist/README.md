## Problem Statement

You are given a list of integers and an integer k. Your task is to print the element at the k-th index (0-based indexing) of the list.

 * If the index k is valid (i.e., within the bounds of the list), print the element at that index.

 * Otherwise, print "Index Not Exist".

### Input
The first line of input contains space-separated integers representing the elements of the list.
The second and last line of input contains a single integer k.

### Output
If the index k is valid (i.e., within the bounds of the list), print the element at that index.
Otherwise, print "Index Not Exist".

### Example
Input
3 25 23 5
3
Output
5
Explanation
The size of the given list is 4 and the index 3 contains element 5.

Input
3 25 23 5
4
Output
Index Not Exist
Explanation
The size of the given list is 4 and we're trying to access the fifth element that do not exist. Thus print "Index Not Exist".
