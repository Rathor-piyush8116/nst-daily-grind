## Problem Statement

You are given three integers a, b, and c in any order. Your task is to determine whether there exists any permutation of these three numbers that forms a valid Arithmetic Progression (AP).

A sequence is said to be an Arithmetic Progression if the difference between consecutive elements is constant. Formally, a sequence x₁, x₂, x₃ is an AP if:

x₂ &minus; x₁ = x₃ &minus; x₂

You may rearrange the given numbers in any order to check this condition.

Important: You are not allowed to use any inbuilt math functions, sort(), sorted(), lists, or any other data structures.

### Input
The input consists of a single line containing three space-separated integers a, b, and c.

### Output
Print YES if a valid arithmetic progression permutation exists, otherwise print NO.

### Example
Examples

Example 1:

Input:

6 2 4

Output:

YES

Explanation:

The numbers can be arranged as (6, 4, 2), which forms an arithmetic progression with common difference -2.

Example 2:

Input:

5 10 3

Output:

NO

Explanation:

No permutation of the numbers results in equal consecutive differences. Hence, no arithmetic progression is possible.

Example 3:

Input:

12 4 -4

Output:

YES

Explanation:

The numbers can be arranged as (-4, 4, 12), which forms an arithmetic progression with common difference 8.
