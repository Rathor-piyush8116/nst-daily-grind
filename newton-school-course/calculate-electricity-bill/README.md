## Problem Statement

You are given the number of electricity units consumed by a customer in a month.

Based on the number of units, you are required to calculate the total bill using the following slab rates:

 * First 100 units &rarr; ₹4 per unit

 * Next 100 units (101&ndash;200) &rarr; ₹5 per unit

 * Next 100 units (201&ndash;300) &rarr; ₹6 per unit

 * Next 100 units (301&ndash;400) &rarr; ₹7 per unit

 * Above 400 units &rarr; ₹8 per unit

After computing the bill based on units consumed, apply a 10% surcharge on the total bill.

The final bill must be rounded to 1 decimal place using the round() function.

### Input
A single integer units — the number of electricity units consumed. 

### Output
Print a single number — the final bill amount (rounded to 1 decimal place), using round()

### Example
Example 1:
Input:
330

Output:
1881.0

Explanation:

 * First 100 units: 100 × ₹4 = 400

 * Next 100 units: 100 × ₹5 = 500

 * Next 100 units: 100 × ₹6 = 600

 * Remaining 30 units: 30 × ₹7 = 210

 * Total before surcharge = 400 + 500 + 600 + 210 = 1710

 * Surcharge (10%) = 171.0

 * Final Bill = 1710 + 171 = 1881.0

Output: 1881.0

-------------------------------------------------------------------------

Example 2:
Input:
80

Output:
352.0

Explanation:

All 80 units fall within the first 100-unit slab, so the bill is 80 × ₹4 = ₹320. After adding 10% surcharge (₹32), the final bill becomes ₹352.0.

// ─── 5 ───
units = int(input())
ans=0
if units<=100:
    ans= units*4
elif 100<units<=200:
    ans=100*4 + (units-100)*5
elif 200<units<=300:
    ans= 100*4+ 100*5 + (units-200)*6
elif 300<units<=400:
    ans= 100*4+ 100*5+ 100*6 +(units-300)*7
else:
    ans= 100*4+100*5+100*6+100*7+(units-400)*8   
total= ans/10
ans = ans+total
