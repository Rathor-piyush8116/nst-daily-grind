## Problem Statement

Write a Python program to print all numbers from 1 to N.

### Input
The first and only line of input contains a single integer N.

### Output
Print all numbers from 1 to N in space-separated manner.

### Example
Input
5
Output
1 2 3 4 5
Explanation
All the numbers from 1 to 5 are printed in space-separated manner

Input
1
Output
1

## Solution

```js
// ─── 2 ───
n = int(input())
for i in range(n):
    print(i + 1,end= " ")
```
