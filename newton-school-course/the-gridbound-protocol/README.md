## Problem Statement

A robot moves across a coordinate grid to reach its destination. The robot can move in one of three modes: Horizontal, Vertical, or Diagonal.

You are given the robot&#39;s starting position (x1, y1), its destination position (x2, y2), and the selected movement mode.

Determine whether the movement is valid according to the following rules:

 * Horizontal: The robot must remain in the same row.

 * Vertical: The robot must remain in the same column.

 * Diagonal: The absolute difference between the x-coordinates must equal the absolute difference between the y-coordinates.

Moving to the same position is always considered invalid.

Print Valid if the movement follows the selected mode&#39;s rule and the starting and ending positions are different. Otherwise, print Invalid.

### Input
The first line contains two integers, x1 and y1, representing the robot's starting position.

The second line contains two integers, x2 and y2, representing the robot's destination position.

The third line contains a string mode, representing the selected movement mode. It will be one of the following:

* Horizontal

* Vertical

* Diagonal

### Output
Print "Valid" if the movement is valid for the selected robot mode and the starting and ending positions are different.

Otherwise, print "Invalid".

### Example
Input:
2 4
2 9
Horizontal

Output:
Invalid

Explanation:
Both positions have the same x-coordinate. Since the positions are different, horizontal movement is Invalid.

Input:
1 2
5 6
Diagonal

Output:
Valid

Explanation:
The absolute difference between the x-coordinates is |5 - 1| = 4, and the absolute difference between the y-coordinates is |6 - 2| = 4. Both differences are equal, so the diagonal movement is valid.

// ─── 2 ───
x1,y1=map(int ,input().split())
x2,y2=map(int ,input().split())
mode = input()
if x1 == x2 and y1 == y2:
    print("Invalid")
elif mode == "Horizontal":
    if y1 == y2:
        print("Valid")
    else:
        print("Invalid")

elif mode == "Vertical":
    if x1 == x2:
        print("Valid")
    else:
        print("Invalid")

elif mode == "Diagonal":
    if abs(x1 - x2) == abs(y1 - y2):
        print("Valid")
    else:
        print("Invalid")
else:
    print("Valid")
