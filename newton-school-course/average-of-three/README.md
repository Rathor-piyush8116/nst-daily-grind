## Problem Statement

Write a program that takes three numbers as input and prints their average.

Note: The result should be rounded to two decimal places.

### Input
The first and only line of input contains three space-separated numbers (integer or float).

### Output
Print the average of the three numbers rounded to two decimal places.

### Example
Input
10 20 30
Output
20.0
Explanation
Average = (10 + 20 + 30) / 3 = 60 / 3 = 20.0

Input
3.3 1.2 1
Output
1.83
Explanation
To calculate the average, we add all the values:
3.3 + 1.2 + 1 = 5.5

Now, divide the total by the number of values:
5.5 ÷ 3 = 1.8333333333333333

Since the question requires the answer to be rounded to two decimal places, we round 1.8333333333333333 to 1.83.

Final Answer: 1.83

## Solution

```js
a,b,c = map(float,input().split())
ans = (a+b+c)/3.0
ans = round(ans,2)
print(ans)
```
