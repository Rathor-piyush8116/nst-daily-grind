## Problem Statement

An electricity board calculates monthly power usage bills based on the number of units consumed using a slab-wise tariff system. Each slab charges a different rate per unit as follows:

 
 First 100 units: ₹4 per unit

 

 
 Next 100 units (i.e., units 101&ndash;200): ₹5 per unit

 

 
 Next 100 units (i.e., units 201&ndash;300): ₹6 per unit

 

 
 Next 100 units (i.e., units 301&ndash;400): ₹7 per unit

 

 
 Units above 400: ₹8 per unit

 

After calculating the base bill, a 10% surcharge is added to the total bill.

You are required to implement the function calculate_bill(units) that calculates the total electricity bill including the surcharge, and returns a float rounded to 1 decimal place using the built-in round() function.
