## Problem Statement

You are given a list of integers of size N and a number X.

Your task is to write a Python program to find and print the index of the first occurrence of X in the list.

Note: If X is not present in the given list, print -1.

### Input
The first line contains two integers N and X - the size of list and the number to search for, respectively.

The second line contains N space-separated integers (the list).

### Output
Print the index (0-based) of the first occurrence of X.
If X is not found, print -1.

### Example
Input
7 2
3 17 9 2 2 25 6
Output
3
Explanation
Element 2 appears first at index 3, so the answer is 3.

Input
5 5
7 4 9 1 6
Output
-1
Explanation
Element 5 is not present in this list, thus we are required to print -1.
