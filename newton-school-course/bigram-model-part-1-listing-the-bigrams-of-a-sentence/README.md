## Problem Statement

When you type a message on a phone, the keyboard suggests the word you are likely to type next. One simple way to make these suggestions is a bigram model. It learns from pairs of words that appear next to each other in sample text.

You will build a bigram model in three parts. In this part, you list the word pairs of a sentence.

A bigram is a pair of two words that appear one right after the other. For example, the sentence i love machine learning has three bigrams:

i love
love machine
machine learning

Each word is paired with the word right after it. The last word has no word after it, so a sentence with N words has N - 1 bigrams.

Task

Write a program that reads one sentence and prints all of its bigrams.

 * Print each bigram on its own line: the first word, one space, and then the second word.

 * Print the bigrams in the order in which they appear in the sentence.

 * If the same pair appears more than once, print it every time it appears.

 * If the sentence has only one word, it has no bigrams. In that case, print NONE.

### Input
A single line containing the sentence. The sentence has N words. The words are in lowercase and are separated by single spaces.

### Output
If N is at least 2, print N - 1 lines. Line i contains word i and word i + 1 of the sentence, separated by one space.

If N is 1, print NONE.

### Example
Example 1:
Input:i love machine learningOutput:i love

Example 2:
Input:the cat sat on the matOutput:the cat

the matExplanation:
The sentence has 6 words, so it has 5 bigrams. The word the appears twice, and each time it starts a new pair: the cat and the mat.

Example 3:
Input:helloOutput:NONEExplanation:
No word comes after hello, so the sentence has no bigrams.

## Solution

```py
// ─── 16 ───
words = input().split()

if len(words) < 2:
  print("NONE")
else:
  bigrams = []
  for i in range(len(words) - 1):
    bigram = words[i] + " " + words[i + 1]
    bigrams.append(bigram)

  for pair in bigrams:
    print(pair)

// ─── 19 ───
i love
love machine
machine learning
```
