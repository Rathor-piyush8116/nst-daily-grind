## Problem Statement

The Government of Maharashtra is running a welfare scheme called "Ladki Bahin Yojana" to support eligible women citizens.

A women is eligible for this scheme if all the following conditions are met:

 
 The gender is "female"

 

 
 The annual income is less than or equal to 2.5 lakhs (i.e &le; 250000)

 

 
 The age is between 21 and 65, inclusive

 

You are given the gender, annual income, and age of a person. Write a program to determine whether the person is eligible for the scheme.

### Input
A single line containing following three variables:
* A string gender ('female' or 'male' only)

* An integer income

* An integer age

Note: All values are space-separated

### Output
Print a single line as following:
* Eligible — if the person satisfies all conditions.

* Not Eligible — otherwise.

Note: Output must exactly match the above (case-sensitive, no extra spaces).

### Example
Input:
female 240000 35

Output:
Eligible

Input:
male 180000 40

Output:
Not Eligible

inc=int(income)
ag=int(age)

    print("Not Eligible")
