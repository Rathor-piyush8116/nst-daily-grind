## Problem Statement

You are given the length and breadth of a rectangle. Define and implement the following function to calculate and return its perimeter:

def perimeter(length, breadth):

After defining the function, take the length and breadth as input, call perimeter(length, breadth), and print the returned result.

Important:

 * Use the function signature def perimeter(length, breadth):.

 * The function must return the perimeter.

 * Take input, call the function, and print the result outside the function.

### Input

The first and only line contains two space separated integers: length and breadth, representing the length and breadth of the rectangle.

### Output

Print a single integer representing the perimeter of the rectangle.

### Example
Input 1:

2 3

Output 1:

10

Explanation:

The perimeter of a rectangle is calculated using the formula:
Perimeter = 2 &times; (length + breadth)
 = 2 &times; (2 + 3)
 = 10

Input 2:

5 4

Output 2:

18

Explanation:

Perimeter = 2 &times; (5 + 4)
 = 18

## Solution

```py
# Your code here
def perimeter(length, breadth):
    return 2 * (length + breadth)
length, breadth = map(int,input().split())
print(perimeter(length, breadth))
```
