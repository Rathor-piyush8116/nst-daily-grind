## Problem Statement

When you type a word on a phone, the keyboard suggests the word that most often came after it in the text it learned from. This is how a bigram model predicts the next word.

This is part 3 of building a bigram model. In part 2, you listed the words that came right after each word. In this part, you use them to predict the next word.

A bigram model gives each possible next word a probability. If the previous word is W, the probability that the next word is X is:

P(X | W) = (number of times X came right after W) / (number of times any word came right after W)

For example, in the text i love cats i love dogs i hate rain, the words that came right after i are love, love and hate:

next word count probability
love 2 2/3
hate 1 1/3

The model predicts the word with the highest probability, so after i it predicts love. All the probabilities for W have the same denominator, so the word with the highest probability is also the word with the highest count.

Task

Write a program that reads a text and a previous word W, and prints the word that the bigram model predicts will come next.

 * Count how many times each word came right after W in the text.

 * Print the word with the highest count.

 * If two or more words share the highest count, print the one that came right after W earliest in the text.

 * If no word ever came right after W, print NONE. This happens when W is not in the text, or when W appears only as the last word of the text.

### Input
Line 1: the text. The text has N words. The words are in lowercase and are separated by single spaces.

Line 2: the previous word W.

### Output
A single line containing the predicted next word, or NONE.

### Example
Example 1:
Input:i love cats i love dogs i hate rain
iOutput:loveExplanation:
After i, love has probability 2/3 and hate has probability 1/3. love is more likely.

Example 2:
Input:i love dogs i love cats
loveOutput:dogsExplanation:
dogs and cats each came right after love once, so each has probability 1/2. dogs came after love first, so the model predicts dogs.

Example 3:
Input:we went home
schoolOutput:NONEExplanation:
school is not in the text, so the model has nothing to predict from.

## Solution

```py
// ─── 9 ───


# Print the word that came right after prev most often.
# If there is a tie, print the one that came right after prev earliest.
# Print NONE if no word came right after prev.

words = input().split()
W = input()

count = {}

for i in range(len(words) - 1):
    if words[i] == W:
        next_word = words[i + 1]

        if next_word not in count:
            count[next_word] = 0

        count[next_word] += 1

if len(count) == 0:
    print("NONE")
else:
    max_word = max(count, key=count.get)
    print(max_word)
```
