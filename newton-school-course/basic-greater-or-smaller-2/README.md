## Problem Statement

Write a program that takes:

 
 A single character input: "G" for greater or "S" for smaller

 

 
 Two space-separated integers

 

Task:
If the character is "G", print the greater of the two numbers using the greater() function.
If the character is "S", print the smaller of the two numbers using the smaller() function.

You are supposed to implement two functions:

 
 greater(a, b) &rarr; Gives greater of two integers a and b.

 

 
 smaller(a, b) &rarr; Gives smaller of two integers a and b.

 

Note: You should implement and then call these functions as required.

 

### Input
The first line contains choice: A single character, either "G" or "S"
The second line contains a, b: Two space-separated integers

### Output
Print the greater or smaller of the two numbers using the given functions.

### Example
Input
G
4 9

Output
9

Explanation
"G" means print the greater number.
Between 4 and 9, the greater is 9, so the output is 9

## Solution

```py
// ─── 2 ───
def greater(a, b):
    if a > b:
        return a
    else:
        return b


def smaller(a, b):
    if a < b:
        return a
    else:
        return b


choice = input()
a, b = map(int, input().split())

if choice == "G":
    print(greater(a, b))
elif choice == "S":
    print(smaller(a, b))

// ─── 7 ───
9
```
