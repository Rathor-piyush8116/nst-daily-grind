## Problem Statement

You are given three integers a, b, and c.

Your task is to determine whether all three numbers are equal.

Print:

 * Numbers are equal if all three numbers have the same value.

 * Numbers are not equal otherwise.

### Input
The first line contains three space-separated integers a, b, and c.

### Output
Print exactly one line:

 * Numbers are equal if all three numbers are equal.

 * Numbers are not equal otherwise.

### Example
Example 1
Input

5 5 5
Output

Numbers are equal
Explanation
All three numbers have the same value.

Example 2
Input

5 5 7
Output

Numbers are not equal
Explanation
The three numbers do not all have the same value.
