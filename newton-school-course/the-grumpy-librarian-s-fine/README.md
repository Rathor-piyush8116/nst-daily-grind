## Problem Statement

Madam Quill has run the Byteland Royal Library for forty years, and she has never forgiven a late book. Her fine rules have grown over the decades, and even she can&#39;t keep track of them any more. Write a program that calculates the fine for her.

Fine by Book Type:

 * Normal book, up to 7 days late &rarr; 2 per day

 * Normal book, more than 7 days late &rarr; 2 per day for the first 7 days, then 5 per day after that

 * Reference book &rarr; 10 per day, from the first day

Fine Limit:

 * The fine can never be more than the price of the book &rarr; if it is, the fine becomes the book&#39;s price

Loyal Member Discount:

 * Member for 5 or more years &rarr; the fine is halved, rounded down

Take the days late, book type, book price and years of membership as input, and print the final fine.

Note:

 * Apply the fine limit first, then the loyal member discount.

 * If the final fine is 0, print No Fine.

### Input
The first line contains an integer days_late, representing the number of days the book is overdue.

The second line contains the book type, either Normal or Reference.

The third line contains an integer book_price, representing the price of the book.

The fourth line contains an integer member_years, representing the number of years the member has been registered.

### Output

* The final fine as a whole number, if it is more than 0

* No Fine , if the final fine is 0

Explanation

First 7 days at 2 = 14, next 3 days at 5 = 15, total 29. That is under the book's price. The member has 6 years, so the fine is halved and rounded down: 29 // 2 = 14.
