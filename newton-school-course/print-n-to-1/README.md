## Problem Statement

Given a positive integer n, write a recursive function that prints all numbers from n to 1. The function should call itself recursively and print each number in decreasing order.

### Input
User Task
This is a function problem. You don’t have to take any input. You are required to complete the function print_reverse() that takes a positive integer n as a parameter and prints all numbers from n to 1 using recursion.

Custom Input
The input contains a single integer n representing the number from which to start printing in reverse order.

### Output
The function should print the numbers from n to 1 on separate lines.

### Example
Input:
5

Output:
5
4
3
2
1

Explanation:
For input n = 5, the function first prints 5, then recursively calls itself with n - 1. This continues as 4, 3, 2, 1, printing each number before making the next recursive call. The recursion stops when n becomes less than or equal to 0.

## Solution

```py
def print_reverse(n):
    if n < 1:
        return 
    print_reverse(n-1)
    print(n)
```
