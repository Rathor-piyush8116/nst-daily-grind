## Problem Statement

You are given a positive integer N. Your task is to find the smallest digit in the given number.

### Input
The first and only line of input contains a positive integer N.

### Output
Print an integer, the smallest digit in the given number.

### Example
Input
2839
Output
2
Explanation
The given number 2839 contains digits: 2, 8, 3 and 9, amongst them 2 is the smallest digit.

## Solution

```js
# Your code here
n=int(input())
s=10
while n!=0:
    d=n%10
    if d<s:
        s=d
    n=n//10
 
print(s)
```
