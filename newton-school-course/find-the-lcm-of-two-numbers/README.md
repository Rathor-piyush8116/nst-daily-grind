## Problem Statement

Write a program that takes two positive integers as input and calculates their Least Common Multiple (LCM).

Note: The LCM (Least Common Multiple) of two numbers is the smallest number that is a multiple of both numbers. It&rsquo;s the smallest number that both numbers can divide without leaving a remainder.

### Input
The first and only line of input contains two space-separated integers, X and Y.

### Output
Print an integer, representing the LCM of the given two numbers.

### Example
Input
2 3
Output
6
Explanation
Given numbers: 2 and 3
The smallest number divisible by both is 6.
✅ So, the LCM of 2 and 3 is 6.

Input
7 5
Output
35
Explanation
Given numbers: 7 and 5
The smallest number divisible by both is 35.
✅ So, the LCM of 7 and 5 is 35.

## Solution

```py
// ─── 2 ───
num1, num2 = map(int,input().split())
num1, num2 = abs(num1),abs(num2)
def gcd(a,b):
    while b:
        a,b = b,a%b
    return a
gcd=gcd(num1,num2)
print(num1*num2//gcd)

// ─── 8 ───
6
```
