## Problem Statement

Write a program that takes a positive integer N as input and print all odd numbers from 1 to N (inclusive).

### Input
The first and only line of input contains a positive integer N.

### Output
Print all odd numbers from 1 to N in space-separated manner.

### Example
Input
5
Output
1 3 5
Explanation
All the numbers from 1 to 5 are printed in space-separated manner.

Input
9
Output
1 3 5 7 9

## Solution

// ─── 12 ───
n = int(input())
for i in range(1,n+1):
    if i%2!=0:
        print(i ,end = " ")
