## Problem Statement

Write a program to calculate the income tax for an individual based on their annual income in Indian Rupees (₹) provided as input. The tax is calculated according to the following slabs:

 
 
 Income Range (₹)
 Tax Calculation
 
 
 
 
 Up to ₹2,50,000
 No tax.
 
 
 ₹2,50,001 to ₹5,00,000
 5% tax on amount between ₹2,50,001 to ₹5,00,000
 
 
 ₹5,00,001 to ₹10,00,000
 ₹12,500 plus 10% tax on amount between ₹5,00,001 to ₹10,00,000
 
 
 Above ₹10,00,000
 ₹62,500 plus 20% tax on amount above ₹10,00,000.
 
 

The program should read the annual income from the user, calculate the tax accordingly, and output the tax amount upto 1 decimal places.

Note: We can round the output to 1 decimal place using print(round(tax,1)).

### Input
A single integer representing the annual income in rupees.

### Output
Print the tax amount as a float number up to 1 decimal places.

### Example
input 
200000

output 
0.0
Explanation: As income is less than 250000, there will not be any tax that the individual is paying, that's why the output is 0.0.

input 
550000

output 
17500.0

Explanation:
Total income = 550000 
1. No tax upto 250000
2. 5% tax in between 250000 to 500000 = 250000*0.05 = 12500.0
3. 10% tax in between 500000 to 1000000, 
there for remaining taxable income = 550000 - 500000 = 50000
10% of 50000 = 50000 * 0.1 = 5000.0
Total Tax to be paid = 0.0 + 12500.0 + 5000.0 = 17500.0

## Solution

```py
n=float(input())
if n<=250000:
    print(0.0)
elif n<=500000:
    print((n-250000)/20)
elif n<=1000000:
    print((n-500000)/10+12500)
else:
    print((n-1000000)/5+62500)
```
