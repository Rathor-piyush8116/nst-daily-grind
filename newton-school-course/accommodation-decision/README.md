## Problem Statement

A student wants to check whether they will stay On-Campus or Off-Campus based on the rules provided in the NST rulebook.

The rules for accommodation are:

 
 If the student is a girl, she will definitely stay On-Campus, irrespective of the year.

 

 
 If the student is a boy:

 
 
 In first year &rarr; he will stay On-Campus

 

 
 In second year &rarr; he will stay Off-Campus

 

 
 

Given the student&#39;s gender and year of study, determine their accommodation type.

### Input
The input consists of two lines:

 * The first line contains a string gender, representing the gender of the student: * G for girl
 * B for boy
 

* The second line contains an integer year, representing the year of study: * 1 for first year
 * 2 for second year
 
 

### Output
Print a single line, either: 
On-Campus or Off-Campus, according to the rules.

### Example
Input
G
2
Output
On-Campus

Input
B
2
Output
Off-Campus
