## Problem Statement

Alice appeared for an exam in one subject. The exam is out of total marks. She wants to know her percentage score.

A predefined function PrintPercentage(total_marks, obtained_marks) is available. It takes two integer arguments:

 
 total_marks &mdash; total marks of the exam

 

 
 obtained_marks &mdash; marks obtained by Alice

 

The function prints the percentage (up to 2 decimal places).

Note: You do not need to define this function, just take the inputs and call this function and it will automatically print the percentage.

### Input
A single line contains two space separated integers total marks and marks obtained by Alice.

### Output
Use the predefined function PrintPercentage() and just call the function.

### Example
Input:
10 8

Output:
80.00

Explanation:
The input line is split into two integers: total_marks = 10 and obtained_marks = 8.

The predefined function PrintPercentage(10, 8) is called.

It calculates:
(8/10)×100=80.00
The function prints 80.00 as the final percentage.
