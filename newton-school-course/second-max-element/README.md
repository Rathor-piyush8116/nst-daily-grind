## Problem Statement

You are given a list of integers. Some numbers may appear more than once.

Your task is to find the second largest distinct number in the list.

Distinct means you should consider each number only once, even if it appears multiple times.

### Input
The first and only line of input contains space-separated integers, representing the elements of the list.

### Output
Print a single integer: the second largest unique number in the list.

### Example
Input
3 17 9 2 25 6
Output
17
Explanation
In the list [3, 17, 9, 2, 25, 6], the largest number 25, and the second largest number is 17. Thus the answer will be 17.

Input
7 4 1 7
Output
4
Explanation
The given list arranged in the sorted order will be [1, 4, 7, 7]. The largest value in the given list is 7, which is appearing twice, thus the second largest value will be 4.
