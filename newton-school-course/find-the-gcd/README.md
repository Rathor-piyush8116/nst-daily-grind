## Problem Statement

Write a program that takes two positive integers as input and calculates their Greatest Common Divisor (GCD). 

Note: The GCD (also known as HCF &ndash; Highest Common Factor) of two numbers is the largest number that divides both of them without leaving a remainder. 

 

### Input
The first and only line of input contains two space- separated integers a and b.

### Output
Print an integer, representing the GCD of given two numbers.

### Example
Input
25 50
Output
25
Explanation
25 is the largest numbers that divides both 25 and 50.

Input
7 13
Output
1
Explanation
No other number greater than 1 divides both 7 and 13 completely.

## Solution

```py
num1 , num2 = map(int,input().split())
num1 , num2 = abs(num1),abs(num2)
def gcd(a,b):
    while b:
        a,b = b,a%b
    return a
gcd = gcd(num1,num2)
print(gcd)
```
