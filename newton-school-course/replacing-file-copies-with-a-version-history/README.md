## Problem Statement

Person X saves every version of a report as a new copy of the file. Person X&#39;s folder now has three copies, and it is hard to tell what changed between them. Git can keep every version of one file, each with a short message. In this question, you replace Person X&#39;s three copies with one file, report.txt, and a Git history of its three versions.

Starting folders

report/
├── notes.txt Person X's private notes: never save this file in Git
├── report_v1.txt version 1 (the oldest)
├── report_v2.txt version 2
└── report_final.txt version 3 (the newest)

Your commands start in the folder that contains report, so first move into report.

Git has not been used on this computer before, so no name or email is set.

Tasks

 * Make a repository and set Person X&#39;s name.

 
 * Make the folder report a Git repository.

 * Set the name Person X and the email personx@college.edu for this repository only. Do not set them for all repositories on the computer.

 
 

 * Keep the notes out of Git.
 
 * In report, create a file named .gitignore with one line of text: notes.txt

 * Do not delete notes.txt.

 
 

 * Save the three versions as three commits of one file, report.txt. Make exactly three commits, in this order:
 
 * Commit 1. Copy report_v1.txt to a new file named report.txt. Add only report.txt and .gitignore, and commit them with the message First draft.

 * Commit 2. Copy report_v2.txt onto report.txt, so that report.txt now has the text of version 2. Add report.txt again, and commit it with the message Second draft.

 * Commit 3. Copy report_final.txt onto report.txt. Add report.txt again, and commit it with the message Final version.

 
 Each message is exactly the words shown, with nothing added. The copy files themselves are never added.

 * Delete the copies. Delete report_v1.txt, report_v2.txt and report_final.txt from the folder. Git now keeps all three versions inside report.txt&#39;s history.

Expected result

report/
├── .git/ the history (newest first): Final version, Second draft, First draft
├── .gitignore one line: notes.txt
├── notes.txt still here, never saved in Git
└── report.txt the text of version 3

cd report
git init

git config user.email "personx@college.edu"

echo "notes.txt" > .gitignore

cp report_v1.txt report.txt
git add report.txt .gitignore
git commit -m "First draft"

cp report_v2.txt report.txt
git add report.txt
git commit -m "Second draft"

git commit -m "Final version"
