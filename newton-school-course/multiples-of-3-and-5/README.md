## Problem Statement

You are given a positive integer N. Your task is to print all numbers between 1 and N (inclusive) that are divisible by both 3 and 5.

### Input
The first and only line of input contains a single integer N.

### Output
Print all numbers from 1 to N that are divisible by both 3 and 5, in increasing order.
The numbers should be printed on a single line, separated by a space.

Note: If there are no such numbers, you need not to print anything.

### Example
Input
30
Output
15 30
Explanation
For input 30, the numbers between 1 and 30 that are divisible by both 3 and 5 are: 15 and 30.

Input
5
Output

Explanation
It can be seen that upto 5, there is no number which is a multiple of 5 and 3 both.

## Solution

```js
// ─── 2 ───
N = int(input())
for i in range(1,N+1):
    if i%3==0 and i%5==0:
        print(i,end=" ")

// ─── 8 ───
15 30
```
