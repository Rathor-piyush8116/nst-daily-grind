## Problem Statement

Write a program that take an integer number n and an integer digit d, then prints one of these messages based on the conditions below:

1. If n is a palindrome and its last digit is d:

 "Number is palindrome and last digit is d"

2. If n is a palindrome but its last digit is not d:

 "Number is palindrome and last digit is not d"

3. If n is not a palindrome:

 "Number is not a palindrome"

Note:

Use the provided isPalindrome(n) function returns True or False. Do not rewrite it.

 

A palindrome number is a number that reads the same backward as forward.
Examples: 121, 1331, 44444

Numbers that are not palindrome do not read the same backward.
Examples: 123, 4567, 1201

### Input
The Input will be the two space-separated integers n and d.

### Output
The output will be the string message as per the problem description.
