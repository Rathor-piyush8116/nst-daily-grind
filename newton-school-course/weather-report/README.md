## Problem Statement

Write a program that takes an integer current temperature as input, and determines the type of weather using the below conditions:

Temp &lt; 0 : Freezing Weather

Temp 0-9 : Very Cold

Temp 10-19 : Cold

Temp 20-29 : Normal

Temp 30-39 : Hot

Temp &gt;=40 : Very Hot

### Input
A line containing an integer number representing the temperature.

### Output
Print the weather according to the temperature as The weather today is classified as: answer

### Example
Input
29
Output
The weather today is classified as: Normal
Explanation
According to the given question the temperature 20-29 are considered Normal

Input
9
Output
The weather today is classified as: Very Cold
Explanation
According to the given question the temperature 0-9 are considered Very Cold

## Solution

```py
temp = int(input())

if temp < 0:
  weather = "Freezing Weather"
elif temp <= 9:
  weather = "Very Cold"
elif temp <= 19:
  weather = "Cold"
elif temp <= 29:
  weather = "Normal"
elif temp <= 39:
  weather = "Hot"
else:
  weather = "Very Hot"

print(f"The weather today is classified as: {weather}")
```
