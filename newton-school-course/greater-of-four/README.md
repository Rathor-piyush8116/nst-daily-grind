## Problem Statement

You are given four integers a, b, c, and d.

A built-in function greater(x, y) is available to you. It returns the greater of the two values x and y.

Your task is to find the greatest among the four given numbers using the greater() function.

Note: You must use the provided greater() function. Do not compare all four numbers directly.

### Input
The first line contains four space-separated integers a, b, c, and d.

### Output
Print a single integer &mdash; the greatest among the four numbers.

### Example
Example 1
Input
10 25 15 24
Output

25

 
Example 2
Input

5 2 8 7
Output

8

## Solution

```js
// ─── 2 ───
a, b, c, d = map(int, input().split())

x = greater(a, b)
y = greater(c, d)

ans = greater(x, y)

print(ans)

// ─── 5 ───
```
