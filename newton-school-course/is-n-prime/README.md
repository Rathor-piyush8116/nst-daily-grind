## Problem Statement

You are given a positive integer N. Your task is to determine whether N is a prime number. Print "YES" if the number is prime, otherwise print "NO".

Note: A prime number is a number greater than 1 that has no positive divisors other than 1 and itself.

 

### Input
The first and only line of input contains a positive integer N.

### Output
Print "YES" if N is a prime number.
Print "NO" otherwise.

### Example
Input
7
Output
YES
Explanation
7 is only divisible by 1 and 7 → Prime → Output "YES"

Input
10
Output
NO
Explanation
10 is divisible by 1, 2, 5, 10 → Not prime → Output "NO"

## Solution

```js
// ─── 2 ───
N = int(input())
cnt=0
for i in range(1,N+1):
    if N%i==0:
        cnt+=1
if cnt==2:
    print("YES")
else:
    print("NO")
```
