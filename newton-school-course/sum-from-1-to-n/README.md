## Problem Statement

You are given a positive integer N. Your task is to calculate and print the sum of all integers from 1 to N (inclusive).

### Input
The first and only line of input contains a single integer N.

### Output
Print an integer, representing the sum of all integers from 1 to N (inclusive).

### Example
Input
10
Output
55
Explanation
The sum of number from 1 to 10 is equal to 55.

Input
20
Output
Total Energy: 210
Explanation
The sum of number from 1 to 20 is equal to 210.

## Solution

```js
n=int(input())
total_sum = 0
for i in range(1,n+1):
    total_sum += i
print(total_sum)
```
