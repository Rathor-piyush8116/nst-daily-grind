## Problem Statement

You are given a single positive integer n. Your task is to print all odd numbers from 1 to n (inclusive of both numbers) on the same line, separated by spaces.

### Input
A single integer n — the upper limit.

### Output
A single line containing all odd numbers from 1 to n (inclusive) on the same line, separated by spaces.

### Example
Example 1:
Input
5
Output
1 3 5 

------------------------------------

Example 2:
Input
8
Output
1 3 5 7

```js
// ─── 2 ───
n=int(input())
```
