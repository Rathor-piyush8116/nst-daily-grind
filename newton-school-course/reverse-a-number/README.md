## Problem Statement

You are given a positive integer N. Your task is to reverse the given number.

### Input
The first and only line of input contains a positive integer N.

### Output
Print an integer, representing the reversed number.

### Example
Input
536446
Output
644635

Input
100
Output
1

## Solution

```js
// ─── 7 ───
n = int(input())
reversed_num = 0

while n > 0:
    digit = n % 10
    reversed_num = (reversed_num * 10) + digit
    n = n // 10

print(reversed_num)
```
