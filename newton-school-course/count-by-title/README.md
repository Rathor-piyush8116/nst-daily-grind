## Problem Statement

Implement a function count_books_by_title that takes two arguments: book_catalog and title. The book_catalog is a list of strings where each string represents the title of a book.

The function should return the number of times the given title appears in the catalog.

Custom Input

Each line contains a single string representing the title of a book.
The last second line of the input will always be the word "stop", which indicates the end of the bokk catalog and should not be included in the list of book titles.
The last line of input contains a single string, the title of the book.

### Output
Returns an integer representing the count of books with the given title.

### Example
Input
Ramayana
Mahabharata
Gita
Gita
stop
Gita

Output
2

## Solution

```py
// ─── 25 ───
def count_books_by_title(book_catalog, title):
    count = 0
    size = len(book_catalog)

    for i in range(0,size):
        if book_catalog[i] == title:
            count += 1

    return count
```
