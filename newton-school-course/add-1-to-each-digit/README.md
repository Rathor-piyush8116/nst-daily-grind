## Problem Statement

Write a program to add 1 to each digit of the given number and print the result.

Note: Consider adding 1 to digit 9 makes it 0.

### Input
The first and only line of input contains a positive integer N.

### Output
Print an integer, the resultant number formed after adding 1 to each digit.

### Example
Input
765392
Output
876403

## Solution

```js
// ─── 2 ───
num = int(input())
ans = 0
pos = 1
while num > 0:
    digit = num%10
    digit = (digit+1)%10
    ans = digit * pos +ans
    pos = pos*10
    num = num // 10

print(ans)

// ─── 8 ───
876403
```
