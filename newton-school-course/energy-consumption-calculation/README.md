## Problem Statement

You are given two integers: units representing the total electricity consumed and cost representing the cost of each unit.

Your task is to write a Python program that calculates the total electricity cost and prints the result.

### Input
The first and only line of input contains two space-separated integers, representing units and cost respectively.

### Output
Print an integer representing the total electricity cost.

### Example
Input
20 10

Output
200

Explanation
Since 20 units of electricity was consumed and the cost per unit is 10. The total cost would be 200.

## Solution

// ─── 2 ───

total = units *cost
print(total)
