## Problem Statement

Calculate the fine for a late return of a library book based on the following details:

For the first 3 days, the fine is Rs. 10.

For the next 4 to 10 days, the fine is Rs. 20.

For any period exceeding 10 days, the fine is Rs.100.

### Input
A line containing an integer representing the number of late days.

### Output
Print a line containing the total fine amount.

### Example
Input
10
Output
20
Explanation
Fine for 10 late days is 20 Rs according to the question.

Input
20
Output
100
Explanation
Fine for 10 late days is 100 Rs according to the question.
