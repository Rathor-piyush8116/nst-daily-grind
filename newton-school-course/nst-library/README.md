## Problem Statement

You are tasked with implementing a library rental system that calculates the rental fee for a single book based on specific criteria.

The rental fee is calculated according to the following rules:

Rental Duration:

 * If the rental duration is between 1 and 3 days, the daily fee is 1 Rupee per day.

 * If the rental duration is between 4 and 7 days, the daily fee is 0.75 Rupees per day.

 * If the rental duration is 8 days or more, the daily fee is 0.50 Rupees per day.

 * If the rental duration is 0 days or negative, output Invalid rental duration.

Book Type:

 * 1 for New Release (add a surcharge of 2 Rs to the total fee).

 * 2 for Classic (apply a discount of 10% on the total fee).

 * 3 for Children&rsquo;s Book (no additional charge or discount).

Membership Status:

 * 1 for Premium (apply an additional 10% discount on the total fee).

 * 2 for Basic (no changes are applied).

Note: The rental fee should be calculated in the given order only. Also, typecast the final amount to integer before printing.

### Input
The first line contains an integer days representing the number of days the book was rented.
The second line contains an integer book representing the type of book.
The third line contains an integer status representing the membership status.

### Output
Print a single line containing either the calculated rental amount or the message Invalid rental duration.

### Example
Input
4
1
1
Output
4
Explanation:
The daily fee is 0.75 rupees for rentals between 4 and 7 days.
For 4 days, the base fee is calculated as 4 × 0.75 = 3 rupees.

Since the book type is a New Release, a surcharge of 2 rupees is added, bringing the total to 5 rupees.

With a Premium membership, a discount of 10% applies.
The discount on 5 rupees is 0.5, so the adjusted amount becomes 4.5 rupees.

After typecasting the final value to an integer, the result becomes 4.
