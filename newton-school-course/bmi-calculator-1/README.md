## Problem Statement

You are asked to determine a person&#39;s Body Mass Index (BMI) based on their weight and height.

The BMI is calculated using the following formula:

BMI = weight / (height_in_meters × height_in_meters)

Here,

 * weight is given in kilograms

 * height is given in centimeters and must be converted to meters

 

You must round the BMI value to exactly 1 decimal place using the built-in round() function.

Based on the rounded BMI value, print the corresponding BMI category:

 * If BMI is less than 18.5, print Underweight

 * If BMI is between 18.5 and 24.9 (inclusive), print Normal weight

 * If BMI is between 25 and 29.9 (inclusive), print Overweight

 * If BMI is 30 or greater, print Obese

### Input
The input consists of two lines as follows:

 * The first line contains an integer weight — the person's weight in kilograms.

 * The second line contains an integer height — the person's height in centimeters.

### Output
Print two lines:

 * First line: the BMI value rounded to one decimal place using round()

 * Second line: the corresponding BMI category.

### Example
Input
60 
165

Output
22.0
Normal weight

Explanation:
BMI = 60/1.65*1.65 = 22.0
22.0 is in range 18.5 to 24.9
Category = Normal weight

## Solution

```py
# Your code here
weight = int(input())
height = int(input())

height = height / 100

bmi = weight / (height * height)

bmi = round(bmi, 1)

print(bmi)

if bmi < 18.5:
    print("Underweight")
elif bmi <= 24.9:
    print("Normal weight")
elif bmi <= 29.9:
    print("Overweight")
else:
    print("Obese")
```
