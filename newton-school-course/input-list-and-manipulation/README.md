## Problem Statement

Dora the Explorer has collected some numbers during her adventures in the forest. Although Dora doesn&rsquo;t like numbers much, she&rsquo;s curious to perform some operations on them. She needs your help as her math-savvy friend to carry out a few tasks.

You are given a list of numbers and a set of operations to perform on it. Help Dora execute each operation and print the list (or result) as described:

Operations to be performed:

 * Insert: Given an index idx and a value val, insert the number val at index idx.

 Print the updated list.

 

 * Remove: Given a number num, remove its first occurrence from the list.

 Print the updated list.

 

 * Odd Index List: Create a new list that includes all elements present at odd indices of the current list.

 Print this new list.

 

 * Extend: Given another list of numbers, extend the current list by adding all elements from the new list to the end of the original list.

 Print the updated list.

 

 * Clear: Remove all elements from the list, making it empty.

 Print the empty list.

### Input
The first line of input contains space-separated integers representing the elements of the list.
The second line contains two space-separated integers representing the index idx and value val respectively.
The third line contains a single integer num.
The fourth line contains space-separated integers representing the elements of the second list.

### Output
After each operation, print the updated list.
