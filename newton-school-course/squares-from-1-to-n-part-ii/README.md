## Problem Statement

You are given a positive integer N. Your task is to print the squares of all integers from 1 to N, on the same line, separated by a space.

### Input
The first and only line of input contains a single integer N.

### Output
A single line containing N space-separated integers, representing the squares of all integers from 1 to N.

### Example
Input
5
Output
1 4 9 16 25

## Solution

```js
// ─── 14 ───
n = int(input())
for i in range(1,n+1):
    print(i**2,end=" ")

// ─── 17 ───
1 4 9 16 25
```
