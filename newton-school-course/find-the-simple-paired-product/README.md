## Problem Statement

You are given a list of integers arr, containing an even number of elements.

Your task is to create a new list where each element is the product of every two consecutive elements from the original list.

In other words:

 * Multiply the 1st and 2nd elements

 * Multiply the 3rd and 4th elements

 * Multiply the 5th and 6th elements

 * ... and so on

Store each of these products in the new list and return it.

### Input
User Task
This is a functional problem. You do not need to handle input or output. 
Your task is to complete the function paired_product() which takes the given list as its input parameter.

Custom Input
A single line containing space-separated integers, representing the elements of the list.

### Output
Return the list containing product of every two consecutive elements from the original list.

### Example
Input
3 17 9 2 25 6
Output
[51, 18, 150]
Explanation
We take pairs:
3 × 17 = 51
9 × 2 = 18
25 × 6 = 150
So, the output list is:
[51, 18, 150]

Input
7 4 9 1

Explanation
We take pairs:
7 × 4 = 28
9 × 1 = 9
So, the output list is:
[28, 9]

// ─── 18 ───
def paired_product(arr):
    result = []
    for i in range(0,len(arr), 2):
        result.append(arr[i] * arr[i + 1])
    return result
