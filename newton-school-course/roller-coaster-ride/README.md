## Problem Statement

A theme park wants to check if Alice can ride their roller coaster. You are given the height (in cm) and age (in years) of Alice.

Eligibility and ticket rules are as follows:

Height Requirements:

 * Less than 120 cm &rarr; Not Allowed

 * 120 &ndash; 140 cm &rarr; Must ride with Adult

 * Above 140 cm &rarr; Can ride alone

Age Restrictions:

 * Less than 5 years &rarr; Not Allowed

 * 5 &ndash; 12 years &rarr; Must ride with Adult

 * Above 12 &rarr; Can ride alone

Ticket Price Calculation:

 * If Allowed Alone &rarr; ₹300

 * Allowed with Adult &rarr; ₹200

Your task is to print whether Alice is allowed to ride or not. If Alice is allowed to ride, print the ticket price of ride in the next line.

Note: Alice&#39;s eligibility is determined by both height and age. If either height or age imposes a stricter restriction, that restriction takes precedence.

 * For example, if her age requires her to ride with an adult, she cannot ride alone even if her height allows it.

 * Similarly, if her age or height disqualifies her from riding, she is not allowed to ride regardless of the other factor.

### Input
The first line of input contains a single integer, representing height.
The second line also contains a single integer, representing age.

### Output
The output should contain one or two lines:

* On the first line, print Alice's riding status:* Not Allowed — if Alice is not allowed to ride.
* Must ride with Adult — if Alice can ride only with an adult.
* Can ride alone — if Alice can ride by herself.

* If Alice is allowed to ride (either with an adult or alone), print the ticket price on the second line (without ₹ sign).

### Example
Input
145
14
Output
Can ride alone
300
Explanation
Height of Alice is greater than 140 cm and also the age is above 12. 
Therefore, Alice can ride alone and the ticket price will be ₹300.

// ─── 2 ───
height = int(input())
age = int(input())

if height < 120 or age < 5:
    print("Not Allowed")

elif height <= 140 or age <= 12:
    print("Must ride with Adult")
    print(200)

else:
    print("Can ride alone")
    print(300)
