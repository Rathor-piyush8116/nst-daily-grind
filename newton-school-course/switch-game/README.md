## Problem Statement

Alice and Bob are controlling a robot using two separate switches.

 
 Alice presses her switch at A seconds after the robot starts and releases it at B seconds.

 

 
 Bob presses his switch at C seconds after the robot starts and releases it at D seconds.

 

Each person holds their switch continuously from the moment they press it until the moment they release it. Sometimes, Alice and Bob may be holding their switches during overlapping time intervals.

What does &ldquo;holding at the same time&rdquo; mean? This refers to the time period during which both switches are being held simultaneously &mdash; that is, the seconds that lie inside both Alice&rsquo;s and Bob&rsquo;s holding intervals.

Your task is to calculate and print the total number of seconds for which both Alice and Bob are holding their switches at the same time.

### Input
The input consists of a single line with four space separated integers: A, B, C, and D.

### Output
Print a single integer — the total number of seconds during which both Alice and Bob were holding their switches down simultaneously.

### Example
Input
2 6 4 8

Output 
2

Explanation 

* Alice holds her button from second 2 to 6.

* Bob holds his button from second 4 to 8.

* The overlap is from 4 to 6, which lasts 2 seconds.

Input
1 5 5 10

Output 
0

Explanation 

* Alice holds from 1 to 5.

* Bob holds from 5 to 10.

* They only meet at second 5, but since Alice releases at 5, there is no overlapping time.

## Solution

```js
// ─── 2 ───
# Your code here
A, B, C, D = map(int, input().split())

start = max(A, C)
end = min(B, D)

if start < end:
    print(end - start)
else:
    print(0)

// ─── 7 ───
2
```
