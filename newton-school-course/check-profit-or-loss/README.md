## Problem Statement

You are given two integers, cost and sell, representing the cost price and the selling price of a product.

Your task is to determine whether the transaction results in a profit, a loss, or no profit and no loss.

Also, you need to calculate the corresponding amount.

### Input
The first line of input contains a single integer, representing cost.
The second line also contains a single integer, representing sell.

### Output
The program should print two lines. 

The first line should contain one of the words Profit, Loss, or No Profit No Loss.

The second line should contain an integer representing the profit or loss amount, and it should be 0 in case of no profit and no loss.

### Example
Input
150
100
Output
Loss
50

Input
100
100
Output
No Profit No Loss
0

## Solution

```py
// ─── 2 ───
cost = int(input())
sell = int(input())
if sell > cost:
    ans=sell-cost
    print("Profit")
    print(ans)
    
elif cost > sell:
    ans=cost-sell
    print("Loss")
    print(ans)
    
else:
    print("No Profit No Loss")
    print("0")
```
