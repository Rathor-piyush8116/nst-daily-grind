## Problem Statement

You are given the lengths of three sides. Your task is to check whether these three sides can form a valid triangle.

 

### Input
The first and only line of input contains three space-separated integers, representing the lengths of three sides.

### Output
Print Yes if the sides form a valid triangle.
Print No otherwise.

### Example
Input
20 10 13
Output
Yes
Explanation
All combinations of side pairs sum to more than the third side. So, a triangle is possible.

Input
2 5 3
Output
No
Explanation
2 + 3 is not greater than 5, so a triangle cannot be formed.

## Solution

// ─── 2 ───
a, b, c = map(int, input().split())

if a + b > c and a + c > b and b + c > a:
    print("Yes")
else:
    print("No")

Yes
