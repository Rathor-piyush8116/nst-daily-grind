## Problem Statement

You are given the available balance in a customer&#39;s bank account and the amount they want to withdraw. The ATM follows these rules:

 * The withdrawal amount must be a positive multiple of ₹100.

 * The requested amount must not exceed the available account balance.

 * The withdrawal amount must not exceed the daily withdrawal limit of ₹20,000.

The ATM checks the withdrawal request in the following order:

1. If the withdrawal amount is not a valid multiple of ₹100 or is not positive, print Invalid Amount.

2. If the requested amount is greater than the available balance, print Insufficient Balance.

3. If the requested amount is greater than ₹20,000, print Daily Limit Exceeded.

4. If all conditions are satisfied, print Withdrawal Successful. Your task is to determine the appropriate message for the given withdrawal request.

### Input
The input contains two space-separated integers in first line :

* balance — the available balance in the customer's bank account.

* amount — the amount the customer wants to withdraw.

### Output
Print exactly one of the following messages according to the withdrawal conditions:

* Invalid Amount

* Insufficient Balance

* Daily Limit Exceeded

* Withdrawal Successful

### Example
Input:
15000 5000

Output:
Withdrawal Successful

Explanation:
The Withdrawal amount is ₹5000.

* ₹5,000 is a positive multiple of ₹100.

* ₹5,000 does not exceed the available balance of ₹15000.

* ₹5,000 is within the daily withdrawal limit of ₹20000.

All conditions are satisfied, so the withdrawal is successful.

Input:
10000 2550

Output:
Invalid Amount

Explanation:
The withdrawal amount is ₹2550, this is not a multiple of ₹100.

Therefore, the ATM rejects the transaction and prints Invalid Amount.
