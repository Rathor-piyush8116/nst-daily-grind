## Problem Statement

Given a number n, write a Python program to check whether the number n is positive, negative, or zero.

 * Print Positive if n is greater than 0

 * Print Negative if n is less than 0

 * Print Zero if n is equal to 0

### Input
The one and only line contains a single integer n.

### Output

Print whether the number is Positive, Negative, or Zero.

### Example
Sample Input 1:
13

Sample Output 1:
Positive

Explanation:

Since 13 is greater than 0, that's why the output is Positive number.

Sample Input 2:
-13

Sample Output 2:
Negative

Explanation:

Since -13 is less than 0, that's why the output is Negative number.

## Solution

```py
n = int(input())
if n>0:
    print("Positive")
elif n<0:
    print("Negative")
else:
    print("Zero")
```
