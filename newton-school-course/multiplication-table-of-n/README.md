## Problem Statement

Given a positive integer N, your task is to print the multiplication table of N from 1 to 10.

Each line should follow the format:

N x i = result

,where i ranges from 1 to 10, and result is the product of N and i.

### Input
The first and only line of input contains a single integer N.

### Output
Print 10 lines, where each line is in format:
N x i = result
,where i ranges from 1 to 10, and result is the product of N and i.
