## Problem Statement

You are given a catalog of books represented as a list of strings. Each string corresponds to the title of a book.

Your task is to write a function search_book_by_title(book_catalog, title) that checks whether a specific book title exists in the catalog.

Return True if the title exists in the catalog, False otherwise.

### Input
User Task
Since this is a functional problem you don't have to take any input, you just need to complete the function search_book_by_title() that takes book_catalog and title as parameters.

Custom Input
The input consists of multiple lines.
Each line contains a single string representing the title of a book.
The second last line of the input will always be the word "stop", which indicates the end of the books and should not be included in the list of book titles.
The last line of input consists a title of the book that needs to be searched.

### Output
Return True if the title exists in the catalog, False otherwise.

### Example
Input
2 States
Harry Potter
Divergent
stop
Divergent
Output
True

Input

def search_book_by_title(book_catalog, title):
    for i in range(len(book_catalog)):
        if book_catalog[i] == title:
            return True
    return False
