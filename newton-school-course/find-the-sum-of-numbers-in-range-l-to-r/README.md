## Problem Statement

Write a program that takes two integers, L and R, as input and calculates the sum of all numbers from L to R inclusive.

### Input
The first line of input contains a single integer L.
The second line of input contains a single integer R.

### Output
Print an integer, representing the sum of all numbers from L to R inclusive.

### Example
Input
5
10
Output
45
Explanation
Numbers in range 5 to 10 are: 5, 6, 7, 8, 9, 10. And their sum is 45.

Input
5
5
Output
5

## Solution

```js
// ─── 2 ───
l = int(input())
r = int(input())
x=0
for i in range(l,r+1):
    x+=i
print(x)

// ─── 5 ───
```
