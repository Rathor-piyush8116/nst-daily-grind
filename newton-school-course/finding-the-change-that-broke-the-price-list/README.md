## Problem Statement

The canteen&#39;s price list, prices.txt, shows broken prices such as 12.00.00. The repository canteen has six commits. One of them broke prices.txt. Two commits after it added good work (weekend hours and sandwiches), and that work must stay. Git&#39;s history shows which commit changed a file, so you can undo that one change and keep everything else.

Starting folders

canteen/ a Git repository with six commits on main
├── hours.txt good
├── menu.txt good
└── prices.txt broken

Your commands start in the folder that contains canteen, so first move into canteen.

Important: commit IDs are different in every run, because the starting folders are made again each time. An ID copied from one run will not work in the next run. Your commands must find the ID themselves, for example by saving Git&#39;s output into a file with &gt;.

Tasks

 * Find the bad commit. The bad commit is the newest commit that changed prices.txt. Save its short ID into a new file bad_commit.txt inside canteen. The short ID is the 7-character ID that git log --oneline shows. You do not need to commit bad_commit.txt.

 * Get the good prices back. In the folder, change prices.txt back to the text it had in the commit just before the bad commit. Change no other file.

 * Commit the repair. Add prices.txt, and commit it with the message Restore price list. This makes a seventh commit, on top of the six commits.

 * Keep the later work. The two commits after the bad commit must stay, so do not move the branch back to an older commit (for example with git reset). Also do not take the whole folder from an old commit: only prices.txt may change.

Useful

 * git log --oneline -- prices.txt lists only the commits that changed prices.txt, newest first.

 * git log -n 1 --format=%h -- prices.txt prints only the short ID of the newest of them.

 * The commit just before commit X can be written X~1.

 * git restore --source=X prices.txt puts the prices.txt of commit X into the folder, and changes no other file.

// ─── 12 ───

cd canteen
bad=$(git log -n 1 --format=%h -- prices.txt)
echo "$bad" > bad_commit.txt
git restore --source="${bad}~1" prices.txt
git add prices.txt
