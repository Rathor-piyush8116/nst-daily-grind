## Problem Statement

Write a program that takes the hour (0-23) in 24-hour format as input and prints whether it is AM or PM.

 
Note:

 * The time is considered AM if the hour is between 0 and 11 (inclusive).

 * The time is considered PM if the hour is between 12 and 23 (inclusive).

### Input
First line will contain an integer hour (0-23) as input.

### Output
The program should print the appropriate answer(AM or PM) based on the hour.

### Example
Example 1
Input:
10

Output:
AM

Example 2
Input:
13

Output:
PM
