## Problem Statement

You are given a 2D matrix mat consisting of n rows and m columns, along with a positive integer target.

Your task is to determine whether the value target exists anywhere in the matrix.

### Input
The first line of input contains two space-separated integers representing the values n and m respectively.
Each of the next n line contains m space-separated integers, where the i-th line represents the i-th row.
The last line of input contains a single integer, the target value.

### Output
Print "True" (without quotes) if the target is found in the matrix.
Otherwise, print "False".

### Example
Input
3 2
1 2
3 4
5 6
4
Output
True
Explanation
The target value 4 is present at position (1, 1).

Input
3 4
9 9 9 9
9 9 9 9
9 9 9 9
1
Output
False

## Solution

```py
// ─── 10 ───
n,m = map(int,input().split())
matrix = []
for i in range(n):
    l1 = list(map(int,input().split()))
    matrix.append(l1)

target = int(input())
ans = False
for i in range(n):
    for j in range(m):
        if matrix[i][j] == target:
            ans = True
            break
    
print(ans)


// ─── 15 ───
True
```
